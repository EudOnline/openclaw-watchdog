# v0.2.0 Release Runbook Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a Markdown runbook that lets a maintainer execute the final `v0.2.0` release workflow step by step, including real-host evidence capture, tag naming, and GitHub release text handoff.

**Architecture:** Keep the existing release-readiness guide as the policy and sequencing document, then add one task-oriented runbook that turns that guidance into exact commands and checkboxes. Wire the runbook into the current docs and add focused docs-surface assertions so the final release path remains discoverable and regression-protected.

**Tech Stack:** Markdown docs, stdlib `unittest`, existing docs-surface coverage, current git tag naming (`v0.1.0`).
